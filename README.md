# DAMAGE BREAKER v0.6.2

ZIPを展開して index.html をPC版Chromeで開きます。単体HTMLでも動作します。

## 探索

- 3 ACT、各10層（うち6層は戦闘）。同じシードと操作で再現でき、各ACTの地図には複数ルートがあります。下から上へ明るいマスを選び、ACT末尾でボスと戦います。ACT III突破後は任意でEXTRAに挑めます。
- 通常戦闘は金貨とカード、デフレーションエネミーは特殊攻撃と強いレリック。未所持の優先候補が尽きると、残る未所持レリックが候補になります。
- ランダムイベントには金貨、回復、カード、HPを代償にする金貨の契約があります。休憩所ではHPを最大35回復するか、火力型・数字調整型・末尾刻印のいずれかでカードを1枚強化します。
- 店ごとにカード4枚の在庫があり、金貨の範囲で複数購入可能です。レリック購入、合成、カード削除はそれぞれ店ごとに1回。合成と削除でデッキは12枚未満にはなりません。
- 価格はカード30金貨、レリック96金貨、合成24金貨、削除30金貨です。

## 戦闘

- 手札を選んで演算盤へ配置し、HOLDで盤を維持したまま引き直します。HOLDは連続2回まで。BURSTは演算盤を左から処理し、レリックと装甲を適用して攻撃します。
- ACT、深さ、敵の格で基準HPが上がります。直近最大5戦の有効BURST最高値の中央値を参考に、基準値の400倍まで調整します。戦闘開始時に確定するため、戦闘中の攻撃で敵の最大HPは変わりません。
- バリアは正のダメージのBURSTを規定回数無効化します。耐久段階はHPの節目で一度止まり、次の有効BURSTで先に進めます。基礎値弱体と最大HP吸命は戦闘終了まで、演算種別の封印は次のBURSTまで持続します。結界は攻撃以外の妨害を1回防ぎます。
- エナジーとドローが変わるレリックを含めて40種類。歴代ダメージは演算上のBURST火力を記録し、戦闘画面の着弾表示には実際に減った敵HPを表示します。9999無量大数を超える演算ダメージは∞です。
- 設定で演出の通常・高速・スキップを選べます。BURST演出中はEscでもスキップ可能です。

## 開発

```sh
node build.mjs
node --test test/*.test.mjs
node test/sim.mjs 96
```

src/map.mjs がルート、src/enemies.mjs が敵と固有防御、src/run.mjs が進行と施設、src/relics.mjs がレリックと演算評価を管理します。検証詳細は QA.md を参照してください。

## v0.5

- 通常敵18種、デフレーションエネミー9種、ACTボス6種、EXTRAボス1種。大蛇、三頭竜、巨像、月蛾などを88×64のピクセルアートで描き直しました。強敵は通常敵より大きく表示します。

- 確定BURSTと実際に減った敵HPは戦闘画面と勝利報酬の結果欄に分けて表示されます。
- 戦闘開始・HOLD・反撃後のドロー、近接・連撃・封印・吸命などの攻撃演出を追加・強化しました。HOLD演出中もEscでスキップできます。

## v0.5.1 報酬選択

- 戦闘後はカード・金貨・レリックについて、それぞれ受け取るか見送ります。選んだカードの絵と取得済みの報酬一覧を、その画面で確認できます。勝利時の自動HP回復も別に表示します。
- イベントでは入手カードの値、消費エナジー、レア度と、HP・金貨の増減を事前に確認できます。受け取り後の画面には、デッキへ追加したカードと実際の増減が表示されます。
- 23件の自動テストと、4方針×96シードの自動プレイを実行。詳細は QA.md を参照してください。

## v0.5.2 自動保存と戦闘表示

- 「中断」でタイトルへ戻り、「つづきから」で探索を再開できます。再読み込み後も、戦闘中の演算盤・敵の妨害・手札・引き順、報酬の取得・見送り、購入・強化の結果が復元されます。
- 保存枠はブラウザごとに1つです。既存の探索があるときに新しく始めるには確認が必要です。保存と記録はブラウザのローカルデータに保持されます。同じ探索は1つのタブでプレイしてください。
- 戦闘中の予測欄で、最終BURSTと実際に減る敵HPを確認できます。敵の反撃で失ったHPも表示し、吸命で最大HPが変わったときの術師のHPゲージを補正しました。
- 「千和の石版」は加算1枚ごとに×60、「万算の算盤」は加算3枚から発動します。有効な自分の演算がすべて加算の場合に発動します。
- 自動保存は src/checkpoint.mjs にあり、保存形式と乱数状態を管理します。

## v0.5.3 強敵のレリック選択

- ACT I・IIのデフレーションエネミーは、候補が残っていれば本来のドロップに加え、加算、乗算、割合、隣接などを軸にしたレリックをもう1つ提示します。両方から1つ獲得するか、見送れます。ボスとACT IIIの強敵のレリックは従来どおり1候補です。
- 地図・施設・報酬画面からデッキを開けます。カードの種類ごとの枚数、各カードの消費、強化済みの印を確認できます。探索終了画面には敗北地点と敵名を表示します。
- v0.5.2で保存した探索からも再開できます。前版の候補がすでに確定している報酬画面は、その時点の内容で復元します。
- 比較データは test/balance-v053-comparison.json に収録しています。シードdb-96から再実行するには `node test/sim.mjs 96 96` を使います。

## v0.5.5 ACT IIIバランス調整

- 「万算の算盤」は有効な自分の演算が加算のみで3〜4枚なら二乗、5枚以上なら三乗です。
- 無量門の王竜の基準HPは8×10¹⁸。星蝕の虚空皇帝の基準HPは5×10¹⁸で、装甲は÷2、直近戦闘を反映するHP係数は中央値の1/3です。王竜の2つの耐久段階と皇帝の2回分のバリアはそれぞれ残ります。
- 戦闘画面でバリア残数と次の耐久段階突破に必要なダメージを確認できます。途中セーブの戦闘では保存時の敵HP、装甲、バリアを使い、次の遭遇から調整後の値を使います。
- [GitHub Pagesで遊ぶ](https://danstars12.github.io/damage-breaker/)

## v0.5.6 通常クリア率の調整

- 通常戦の勝利回復は7、デフレーションエネミーは13、ACTボスは28。勝利後のHP上限は100です。
- ACT I・II・IIIのボスの通常攻撃はそれぞれ12・18・25ダメージ。二連撃は各ボスの攻撃力から計算します。
- 目標は4方針の自動プレイで通常クリア率70％前後です。測定方法と方針別の結果は QA.md を参照してください。

## v0.5.7 戦闘演出

- 初遭遇時に敵が登場し、ボス・EXTRAには専用の登場演出があります。
- BURSTでは演算中の魔法陣、術師から敵への弾道、着弾の衝撃波が順に出ます。大ダメージ、バリア、耐久段階突破で着弾が変わり、撃破時には敵が消えます。
- 高速・軽量では演出を短縮し、発光の重ね描きを減らします。演出スキップやEscキーで演算結果へすぐ進めます。

## v0.5.8 カード削除の確認

ショップで「削除するカードを選ぶ」を押し、対象のカードを選択して確定します。料金とカードのプレビューを確認してから削除できます。

## v0.5.9 レリック発動表示と敵名

- 所持レリックの説明を常時表示します。発動可能なものに紫の目印がつき、演算で効果が適用された瞬間に金色で発光します。演出をスキップしても、実際に発動したレリックは直前のBURST結果で確認できます。
- 通常敵18体、強敵9体、ACTボス6体、EXTRA1体をカタカナ名に改名しました。以前のセーブから戦闘を再開すると、新しい名前が表示されます。

## v0.6.0 カード配置の取り消しと削除演出

- そのターンに演算盤へ置いたカードは仮置きです。選択して「手札に戻す」を押すか、手札へドラッグすると、消費したエネルギーも戻ります。HOLDやBURSTで確定し、浄化と結界は使用時に効果が適用されます。
- ショップではカードと料金を確認してから削除します。確定すると選んだカードが魔法陣とともに消え、カード名・料金・残り枚数を確認できます。

## v0.6.1 戦闘予測とSE

- HOLDとBURSTの比較欄に、反撃による敗北、今の盤での撃破、バリアや耐久段階の突破を表示します。HOLD後に妨害で火力が変わる場合は、新しいカードを引く前の演算結果を表示します。
- カードの設置・移動・手札への復帰、ドロー、結界・封印、BURSTの着弾や耐久段階の突破、報酬・工房操作にSEを追加。設定から音量を変えられます。
- 二連撃は術師が2回のけぞり、結界で妨害を防いだときは術師が緑に光ります。耐久段階の突破には亀裂の演出を追加しました。HOLDの反撃演出も画面のボタンとEscでスキップできます。
- ACT IIIのアエテル・ドラゴンロードは攻撃値を25から24に下げました。通常攻撃は24、二連撃は16×2です。

## v0.6.2 ボスと魔導具

- レリックは40種。コモン、レア、エピック、レジェンドの4段階で、すべてにドットアイコンを追加しました。基礎値を伸ばすものや、HOLD・強化済みパネル・降順配置を活かすものが増えました。
- 鍛冶では強化前後のカードを並べ、打刻と火花を表示します。基礎値が上がるレリックの取得時とACT進行時に、基礎値の変化を表示します。
- 全6体のACTボスに出現演出と固有攻撃を追加しました。二連撃に加え、三段追撃、ドローとエナジーの一時減少、局所封印、竜炎の刻印が登場します。結界は複合技の妨害部分を防ぎます。
- デッキはカードの見た目で種類順に表示します。種類で絞り込め、12枚ごとにページを切り替えられます。店舗はカード・レリック・工房に分かれ、調整画面の縦幅も詰めました。
