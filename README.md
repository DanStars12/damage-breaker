# DAMAGE BREAKER v0.5.1

ZIPを展開して index.html をPC版Chromeで開きます。単体HTMLでも動作します。

## 探索

- 3 ACT、各10層（うち6層は戦闘）。同じシードと操作で再現でき、各ACTの地図には複数ルートがあります。下から上へ明るいマスを選び、ACT末尾でボスと戦います。ACT III突破後は任意でEXTRAに挑めます。
- 通常戦闘は金貨とカード、デフレーションエネミーは特殊攻撃と強いレリック。未所持の優先候補が尽きると、残る未所持レリックが候補になります。
- ランダムイベントには金貨、回復、カード、HPを代償にする金貨の契約があります。休憩所ではHPを最大35回復するか、火力型・数字調整型・末尾刻印のいずれかでカードを1枚強化します。
- 店ごとにカード4枚の在庫があり、金貨の範囲で複数購入可能です。レリック購入、合成、カード削除はそれぞれ店ごとに1回。合成と削除でデッキは12枚未満にはなりません。
- 価格はカード30金貨、レリック96金貨、合成24金貨、削除30金貨です。

## 戦闘

- 手札を選んで演算盤へ配置し、HOLDで盤を維持したまま引き直します。HOLDは連続2回まで。BURSTは演算盤を左から処理し、レリックと装甲を適用して攻撃します。
- ACT、深さ、敵の格で基準HPが上がります。直近最大5戦の有効BURST最高値の中央値を参考に、基準値の400倍まで調整します。戦闘開始時に確定するため、戦闘中の攻撃で敵の最大HPは変わりません。
- バリアは正のダメージのBURSTを規定回数無効化します。耐久段階はHPの節目で一度止まり、次の有効BURSTで先に進めます。基礎値弱体と最大HP吸命は戦闘終了まで、演算種別の封印は次のBURSTまで持続します。結界は攻撃以外の妨害を1回防ぎます。
- エナジーとドローが変わるレリックを含めて20種類。歴代ダメージは演算上のBURST火力を記録し、戦闘画面の着弾表示には実際に減った敵HPを表示します。9999無量大数を超える演算ダメージは∞です。
- 設定で演出の通常・高速・スキップを選べます。BURST演出中はEscでもスキップ可能です。

## 開発

```sh
node build.mjs
node --test test/*.test.mjs
node test/sim.mjs 96
```

src/map.mjs がルート、src/enemies.mjs が敵と固有防御、src/run.mjs が進行と施設、src/relics.mjs がレリックと演算評価を管理します。検証詳細は QA.md を参照してください。

## v0.5

- 通常敵18種、デフレーションエネミー9種、ACTボス6種、EXTRAボス1種。大蛇、三頭竜、巨像、月蛾などを88×64のピクセルアートで描き直しました。強敵は通常敵より大きく表示します。
- ランダムイベント10種。支払える金貨や生存に必要なHPが足りない場合は見送れます。
- 敵が落としたレリックは、効果を読んでから取得または見送りを選びます。ショップは購入を選んだ時点で取得します。
- 「千和の石版」「万算の算盤」は有効な加算パネルだけで発動します。乗算・割合・多種演算に反応するレリックと、構築に影響する取引条件付きレリックも加えました。
- 確定BURSTと実際に減った敵HPは戦闘画面と勝利報酬の結果欄に分けて表示されます。
- 戦闘開始・HOLD・反撃後のドロー、近接・連撃・封印・吸命などの攻撃演出を追加・強化しました。HOLD演出中もEscでスキップできます。

## v0.5.1 報酬選択

- 戦闘後はカード・金貨・レリックについて、それぞれ受け取るか見送ります。選んだカードの絵と取得済みの報酬一覧を、その画面で確認できます。勝利時の自動HP回復も別に表示します。
- イベントでは入手カードの値、消費エナジー、レア度と、HP・金貨の増減を事前に確認できます。受け取り後の画面には、デッキへ追加したカードと実際の増減が表示されます。
- 23件の自動テストと、4方針×96シードの自動プレイを実行。詳細は QA.md を参照してください。
