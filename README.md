# DAMAGE BREAKER v1.3.3

公開版はPCとスマートフォンのブラウザで遊べます。オフラインで遊ぶ場合は、ZIPを展開してブラウザで index.html を開きます。単体HTMLでも動作します。

## BURST演出

- 通常演出では、確定BURSTが1億以上かつ敵HPを削った着弾で75〜210msのヒットストップ。耐久ライン突破は最大95ms。高速・軽量では1兆以上の着弾のみ45msで、演出スキップ時には挟みません。
- ダメージを増幅したレリックは発動前後の数値と倍率を表示します。10倍以上は専用SEで強調し、通常演出では数値を読む時間を取ります。
- 歴代記録を出した戦闘の勝利報酬に、記録値と演算式を表示します。途中の一撃で記録を出した場合も、戦闘の決着後に見返せます。

## 戦闘画面の操作

- HOLDとBURSTのボタン内に行動結果の見込みが出ます。敵HPバーの斜線は、現在の式で削れるHPの範囲です。
- 選択したカードの位置と演算を演算盤の下に表示します。仮置きしたカードが2枚以上あると一括で手札に戻せます。
- PCでは演算盤のカードにフォーカスを合わせて、左右キーで移動、Deleteで仮置きを取り消し、Escで選択を解除できます。

## 探索

- 3 ACT、各10層（うち6層は戦闘）。同じシードと操作で再現でき、各ACTの地図には複数ルートがあります。下から上へ明るいマスを選び、ACT末尾でボスと戦います。ACT III突破後は任意でEXTRAに挑めます。
- 通常戦闘は金貨とカード、デフレーションエネミーは特殊攻撃と強いレリック。未所持の優先候補が尽きると、残る未所持レリックが候補になります。
- ランダムイベントは全40種。銀鏡の交換市では、所持するレリックを一つ選び、同じレアリティの未所持品を最大2候補から選んで交換できます。天文写本の蔵、白霧の薬師街、氷柱の宝庫、百階の貸本塔、夕映えの野営隊も追加しました。休憩所ではHPを最大35回復するか、火力型・数字調整型・末尾刻印のいずれかでカードを1枚強化します。
- 店ごとにカード4枚の在庫があり、金貨の範囲で複数購入可能です。レリック購入、合成、カード削除はそれぞれ店ごとに1回。合成と削除でデッキは12枚未満にはなりません。
- 価格はカード30金貨、レリック96金貨、合成24金貨、削除30金貨です。

## 戦闘

- 手札を選んで演算盤へ配置し、HOLDで盤を維持したまま引き直します。HOLDは通常連続2回まで。「凪刻の砂時計」で上限が1回増えます。BURSTは演算盤を左から処理し、レリックと装甲を適用して攻撃します。
- ACT、深さ、敵の格で基準HPが上がります。直近最大5戦の有効BURST最高値の中央値を参考に、基準値の400倍まで調整します。戦闘開始時に確定するため、戦闘中の攻撃で敵の最大HPは変わりません。
- バリアは正のダメージのBURSTを規定回数無効化します。耐久段階はHPの節目で一度止まり、次の有効BURSTで先に進めます。基礎値弱体と最大HP吸命は戦闘終了まで、演算種別の封印は次のBURSTまで持続します。結界は攻撃以外の妨害を1回防ぎます。
- エナジーとドローが変わるレリックを含めて48種類。歴代ダメージは演算上のBURST火力を記録し、戦闘画面の着弾表示には実際に減った敵HPを表示します。9999無量大数を超える演算ダメージは∞です。
- 設定で演出の通常・高速・スキップを選べます。BURST演出中はEscでもスキップ可能です。

## 開発

```sh
node build.mjs
node --test test/*.test.mjs
node test/sim.mjs 96
```

src/map.mjs がルート、src/enemies.mjs が敵と固有防御、src/run.mjs が進行と施設、src/relics.mjs がレリックと演算評価を管理します。検証詳細は QA.md を参照してください。

## v0.6.4 迎撃BURST

- 敵名は戦闘見出しに全文を表示し、中点の区切りを優先して折り返します。狭い画面では敵名を横幅いっぱいに表示します。
- 迎撃BURSTは各戦闘で1回。エネルギーを1残し、有効な演算2枚以上で敵HPを削れるとき、敵の直後の攻撃を1ヒット防ぎます。連撃の残りや複合技の妨害には、防御や結界も活用できます。
- 浄化は演算盤で左側にある妨害から解除します。戦闘ログには、防御や迎撃を適用したあとの実際の被ダメージを表示します。

## v1.2 星詠みの頁

- 二連撃・三連撃は一撃ずつ描画し、迎撃、防御、HP減少が各段で分かります。術師の結界・防御と敵バリアは色の異なる盾で表示します。
- 「破界の一撃」は結界を最大2層破壊します。迎撃が成立すると破界も防げます。「鏡砕きの槌」は有効演算4枚以上のBURSTで敵バリアを最大2層削ります。バリアで止まったBURSTのダメージは敵HPに通りません。
- 星詠みの頁は、戦闘報酬（通常戦・ボス2.5%、デフレーション9%）、ショップの希少在庫（14%、54金貨）、イベント「天球占いの小屋」で獲得します。探索中に持ち運べます。
- 星詠みは、手札の演算をエネルギーと枠の範囲で選び、すでに置いたカードの相対順を保ちながら、レリック・装甲込みで最大ダメージになる場所へ仮置きします。同じダメージなら少ないエネルギーを優先します。補助カードの使用は手動で行えます。ダメージを伸ばせた場合だけ頁を1枚使います。
- 店の「カードを合成」から同じ系統の素材を2枚、休憩所の「カードを強化」から対象1枚と強化方式を選びます。完成カードを確認して確定できます。
- 新規レリック6種、イベント4種、店舗と休憩所の背景、所持金・価格・報酬にドットの金貨アイコンを追加しました。

## v1.3 演算の紋章

- カードは演算ごとの図柄と色、ボタンと地図はドット調の縁とアイコンで表示します。休憩所の目印はテントです。ACT I〜IIIとEXTRAでは地図と戦闘に固有の背景がつきます。
- BURSTは1〜72桁それぞれに発光色、火花の広がり、動きの強さと時間を設定します。大きな桁の帯では斬撃、波紋、彗星などの形と術師のモーションも変化し、∞は専用演出になります。
- ボスの耐久ラインをHPバーに表示します。次に止まるHP、必要ダメージ、突破済みの線、バリアの残り層と装甲は敵側に表示します。
- 迎撃BURSTを休止しました。「凪刻の砂時計」でHOLD上限を増やし、９種の新レリックで交互配置、降順、両端の値一致、短い式での速攻、加算で挟む累乗、割合の合計、３回HOLD、異なる３種、指数で締める式を強化できます。
